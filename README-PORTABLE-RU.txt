ReClip Portable для Windows 11
==============================

Это портативная сборка ReClip для Windows 11.
Она уже содержит всё необходимое для работы:

  - приложение ReClip;
  - портативный Python;
  - нужные Python-библиотеки, включая Flask и yt-dlp;
  - портативный FFmpeg;
  - BAT-файлы для запуска и обновления.

Главное преимущество этой сборки: её не нужно устанавливать в Windows.
Папку можно перенести на другой компьютер, флешку или внешний диск и запускать оттуда.


Как запустить ReClip
--------------------

1. Откройте папку ReClip-Portable.

2. Запустите файл:

     start-reclip-autobrowser.bat

3. После запуска должно открыться окно консоли.
   В нём появится примерно такой адрес:

     http://127.0.0.1:8899

4. Обычно вкладка в браузере открывается автоматически.
   Если она не открылась, откройте браузер вручную и вставьте адрес:

     http://127.0.0.1:8899

5. После этого можно пользоваться ReClip через браузер.


Как остановить ReClip
---------------------

Чтобы остановить приложение:

1. Перейдите в окно консоли, где запущен ReClip.

2. Нажмите:

     Ctrl + C

3. Если появится вопрос о завершении процесса, подтвердите действие.

Также можно просто закрыть окно консоли, но лучше использовать Ctrl + C.


Как перенести ReClip на другой компьютер
----------------------------------------

Переносить нужно всю папку целиком:

  ReClip-Portable

Не копируйте отдельно только папку app, python, ffmpeg или отдельные BAT-файлы.
Они работают вместе как единая портативная сборка.

Правильный порядок:

1. Запакуйте всю папку ReClip-Portable в ZIP-архив.

2. Перенесите ZIP-архив на другой компьютер.

3. Распакуйте архив в удобное место, например:

     D:\PortableApps\ReClip-Portable

4. Запустите:

     start-reclip-autobrowser.bat

На новом компьютере не требуется отдельно устанавливать:

  - Python;
  - FFmpeg;
  - Git;
  - pip.

Всё уже лежит внутри портативной папки.


Куда сохраняются скачанные файлы
--------------------------------

Скачанные видео и аудио сохраняются в папку:

  data\downloads

Она находится внутри папки ReClip-Portable.

Если нужно освободить место, можно вручную удалить ненужные файлы из этой папки.


Если YouTube перестал скачиваться
---------------------------------

YouTube периодически меняет свои механизмы защиты и выдачи видео.
Из-за этого загрузка может перестать работать, хотя сама программа установлена правильно.

В этом случае запустите файл:

  update-ytdlp.bat

Он обновит yt-dlp внутри портативной сборки.
Системные настройки Windows при этом не меняются.

После обновления снова запустите:

  start-reclip-autobrowser.bat


Если браузер не открылся автоматически
--------------------------------------

Это не критическая ошибка.

Проверьте, что в окне консоли написано:

  Running on http://127.0.0.1:8899

После этого откройте браузер вручную и перейдите по адресу:

  http://127.0.0.1:8899


Если Windows Defender долго проверяет программу
-----------------------------------------------

При первом запуске на новом компьютере Windows Defender может проверять файлы дольше обычного.
Это нормально для портативных программ, особенно если они распакованы из ZIP-архива.

Обычно повторные запуски проходят быстрее.


Рекомендуемый путь для распаковки
---------------------------------

Лучше распаковывать сборку в простой путь без русских букв и специальных символов.

Хороший пример:

  D:\PortableApps\ReClip-Portable

Нежелательный пример:

  C:\Users\Имя пользователя\Рабочий стол\Мои программы\ReClip-Portable

Причина простая: некоторые Python-библиотеки и внешние утилиты на Windows иногда хуже работают с длинными путями, пробелами или кириллицей.


Что находится внутри сборки
---------------------------

Основные папки и файлы:

  app\
    Само приложение ReClip.

  python\
    Портативный Python и установленные библиотеки.

  ffmpeg\
    Портативный FFmpeg и FFprobe.

  data\downloads\
    Папка для скачанных видео и аудио.

  start-reclip-autobrowser.bat
    Главный файл запуска.

  update-ytdlp.bat
    Обновление yt-dlp, если YouTube снова начал выдавать ошибки.


Частые проблемы
---------------

1. Ошибка: Could not fetch video

Возможные причины:

  - YouTube изменил выдачу видео;
  - yt-dlp устарел;
  - видео недоступно в вашем регионе;
  - видео требует входа в аккаунт;
  - ссылка ведёт на ограниченный, приватный или удалённый ролик.

Что сделать:

  1. Запустите update-ytdlp.bat.
  2. Потом снова запустите start-reclip.bat.
  3. Проверьте другую ссылку YouTube.

2. Ошибка: [WinError 2] Не удается найти указанный файл

В этой портативной сборке такая ошибка уже должна быть исправлена.
Если она всё же появилась, значит повреждена структура папки или удалён один из внутренних файлов.

Проверьте, что внутри ReClip-Portable есть папки:

  python\
  ffmpeg\
  app\

3. ReClip запустился, но страница не открывается

Откройте вручную:

  http://127.0.0.1:8899

Если страница всё равно не открывается, проверьте, не заблокировал ли запуск антивирус или брандмауэр.


Важно
-----

ReClip запускается локально на вашем компьютере.
Адрес 127.0.0.1 означает «этот же компьютер».
Это не публичный сайт и не внешний сервер.

Скачивайте только те материалы, на которые у вас есть права.
